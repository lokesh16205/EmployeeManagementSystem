# Employee Management System

A Java-based **Employee Management System** developed using **Java, JDBC, and MySQL**. This project follows a layered architecture using **DAO, Service, Manager, and Model** classes to perform employee management operations.

---

## 🚀 Features

- Add Employee
- Update Employee
- Delete Employee
- View Employee Details
- Department Management
- Salary Management
- Attendance Management
- MySQL Database Integration
- Layered Architecture (DAO, Service, Manager)

---

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/lokesh16205/EmployeeManagementSystem.git
```

2. Open the project in IntelliJ IDEA.

3. Create the required MySQL database and tables.

4. Update the database configuration in:

```
src/database/DBConnection.java
```

5. Run:

```
Main.java
```
