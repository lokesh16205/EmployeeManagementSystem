# Employee Management System

A Java-based Employee Management System developed using JDBC and MySQL. This project demonstrates CRUD operations and follows a layered architecture using DAO, Service, and Manager classes.

---

## Features

- Add Employee
- Update Employee
- Delete Employee
- View Employee Details
- Department Management
- Salary Management
- Attendance Management
- MySQL Database Integration

---

## Technologies Used

- Java
- JDBC
- MySQL
- IntelliJ IDEA
- Git
- GitHub

---

## Project Structure

```
src
├── dao
├── database
├── manager
├── model
├── service
├── utility
└── Main.java
```

---

## How to Run

1. Clone the repository

```
git clone https://github.com/lokesh16205/EmployeeManagementSystem.git
```

2. Open the project in IntelliJ IDEA.

3. Create the required MySQL database and tables.

4. Update the database credentials in:

```
src/database/DBConnection.java
```

5. Run:

```
Main.java
```
